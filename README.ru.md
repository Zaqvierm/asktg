# AskTg

[English](README.md) | Русский

Открытый исходный код: [github.com/Zaqvierm/asktg](https://github.com/Zaqvierm/asktg).

AskTg связывает локальные Codex-агенты через Telegram: они могут согласовывать роли, передавать задачи и отправлять отчёты. Каждый участник запускает свою копию плагина и использует собственного Telegram-бота.

AskTg не подключается к GitHub и сам не меняет репозитории. Код и Git-операции остаются на стороне Codex с локальными checkout и GitHub-авторизацией. Необязательный unattended runner по умолчанию выключен.

Для Telegram используется HTTPS Bot API. Нужен только токен своего бота `BOT_TOKEN`; `API_ID` и `API_HASH` не требуются.

## Требования

- Codex с поддержкой плагинов.
- Python 3.11 или новее в `PATH`.
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather).

## Первый запуск

При первой настройке агент проведёт владельца через шаги в @BotFather и запустит локальный мастер AskTg. Токен вводится только в скрытый запрос мастера в локальном терминале; не отправляйте его в чат Codex.

1. Откройте @BotFather в Telegram. Если бота ещё нет, отправьте `/newbot` и выполните инструкции.
2. В настройках бота в @BotFather включите **Bot-to-Bot Communication Mode**.
3. Скопируйте HTTP API token и вернитесь в локальный терминал, где агент запустил мастер. Введите токен в скрытый запрос.

Мастер создаёт отдельное Python-окружение и устанавливает зависимости вне папки плагина. Если запускать вручную:

```text
# Windows
py -3.11 scripts/setup.py

# macOS / Linux
python3.11 scripts/setup.py
```

Настройки хранятся вне плагина:

- Windows: `%APPDATA%\AskTg\credentials\.env`
- macOS/Linux: `$XDG_DATA_HOME/asktg/credentials/.env` или `~/.local/share/asktg/credentials/.env`

Мастер не печатает токен. Необязательный runner остаётся выключенным, пока владелец сам не включит его и не задаст доверенного координатора. После настройки откройте новый тред Codex, чтобы MCP загрузил локальные параметры.

Старые `.env` от версии Telethon могут содержать `API_ID` и `API_HASH`; новый код их игнорирует. Чтобы пересохранить настройки без этих полей, запустите `python scripts/setup.py --reconfigure`.

## Подключение проектной группы

1. Создайте закрытую Telegram-группу и добавьте в неё ботов участников.
2. Включите Bot-to-Bot Communication Mode в @BotFather для участвующих ботов. Один токен не должен одновременно использоваться другим polling listener или webhook: Telegram допускает только один способ доставки обновлений.
3. Запустите listener. Напишите `/start` своему боту в личном чате, затем отправьте в группе `/asktg_group@<имя_вашего_бота>`. AskTg ответит ID группы.
4. Добавьте этот ID в `ASKTG_AGENT_GROUP_IDS` на компьютерах участников и перезапустите listener или откройте новый тред Codex.
5. Для запуска задач без участия владельца отдельно укажите числовой Telegram ID доверенного координатора в `ASKTG_AGENT_TRUSTED_SENDERS`. Не копируйте чужие `.env` и файлы сессий.

Из-за настроек приватности Telegram групповые сообщения ботам нужно адресовать: используйте команду вида `/asktg_task@имя_бота` или отвечайте на сообщение бота. Отключать Group Privacy обычно не требуется.

## MCP-инструменты и хуки

Плагин предоставляет `sync_chats`, `list_known_chats`, `send_telegram_message`, `get_agent_instructions` и `setup_status`. Указывайте `chat_id` разрешённой группы; AskTg принимает сообщения только из групп, явно добавленных в локальную конфигурацию.

Хуки Codex проверяют входящие сообщения при старте треда, после инструментов и перед завершением хода. Просмотрите и доверьте хуки в Codex. Они не будят бездействующий тред; необязательный runner может запустить отдельный процесс `codex exec`.

## Необязательный unattended runner

По умолчанию `ASKTG_AGENT_AUTO_RUN=0`. При включении мастер попросит ID агента, имя его бота, доверенные числовые ID координаторов, имена ботов-партнёров, локальный путь к checkout проекта и лимит времени.

Runner принимает явные `/asktg_task@<этот_бот>` только из разрешённой группы и от локально доверенного отправителя. Поле `approved_by` — заявление координатора, а не независимая проверка голосования. Runner не коммитит, не пушит, не создаёт PR и не делает merge — это остаётся задачей Codex и GitHub.

После настройки запускайте listener и runner отдельно из корня плагина:

```text
python scripts/launch_listener.py
python scripts/launch_runner.py
```

Runner работает в переднем плане; остановите его через Ctrl+C.

## Разработка плагина

- `PREINSTALL_PROMPT.md` содержит инструкции для `$plugin-creator`.
- `skills/asktg-setup/SKILL.md` описывает первичную настройку.
- `skills/asktg-control/SKILL.md` описывает координацию агентов.
- `hooks/hooks.json` регистрирует хуки, `.mcp.json` запускает локальный MCP-сервер.

Не добавляйте `.env`, runtime-данные, Telegram-сессии и `Memory.md` в Git или архив.
