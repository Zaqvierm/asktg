# AskTg plugin pre-install prompt

Use this prompt in Codex with the `$plugin-creator` skill while working from a clean AskTg source checkout:

```text
Use $plugin-creator to prepare the AskTg Codex plugin from this repository.

Create plugin `asktg` in the default personal plugin directory and add it to the default personal marketplace. Bundle the local AskTg MCP server, the setup and control skills, the Codex lifecycle hooks, the portable launcher/setup scripts, and the project documentation. Keep the unattended Codex runner disabled by default.

Use the compatibility layout generated by plugin-creator: `.codex-plugin/plugin.json`, `.mcp.json`, `skills/`, `hooks/hooks.json`, and `scripts/`. Do not add a `hooks` field to `plugin.json`; the hooks file is discovered by Codex. Use a clean local Python runtime in the per-user data directory, not a virtualenv inside the plugin folder.

The plugin must support Windows, macOS, and Linux with Python 3.11+. It uses the HTTPS Bot API and needs only each owner's BOT_TOKEN. The setup skill must guide the owner through @BotFather: create a bot with `/newbot` if needed, enable Bot-to-Bot Communication Mode, then copy the token. The agent should start the local setup wizard in an interactive terminal and let the owner enter the token using hidden input. Never ask for, print, log, or place secrets in the Codex conversation, MCP manifest, source tree, marketplace, Git history, or archive. Store credentials outside the plugin and set file permissions where the OS supports them. If no interactive terminal is available, explain that limitation and give the owner the exact local command without asking for the token in chat.

Add a short default prompt to configure AskTg after installation and keep this pre-install prompt as a separate source document. Update AgentInstructions.md and the two skills so they clearly separate setup, inviting, agreement, task dispatch, reports, and Git/GitHub work. AskTg must not perform GitHub operations. State plainly that the runner trusts its local coordinator and does not independently verify `approved_by` votes.

Use MIT license, display name and developer name AskTg, category Productivity, semver 1.1.0, and repository URL `https://github.com/Zaqvierm/asktg`. Keep the marketplace source at `./plugins/asktg`, installation AVAILABLE, authentication ON_INSTALL, and omit product gating.

Do not copy the donor project's Memory.md, .env files, credentials, Telegram sessions, runtime state, outgoing messages, .venv, caches, or private machine paths. Create a fresh local Memory.md with generic project notes and gitignore it. Do not create a second GitHub repository or publish the Codex plugin to a marketplace. Run the plugin-creator validator and report any environment or live Telegram checks that still require owner credentials.
```

This prompt prepares the package and its local Codex integration. Telegram credentials are entered only in the local hidden setup prompt, never in chat.
